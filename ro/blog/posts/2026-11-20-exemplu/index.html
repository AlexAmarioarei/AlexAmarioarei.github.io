Aceasta este prima postare de pe acest blog și pornește de la întrebarea din spatele statisticilor de scanare: atunci când într-un șir de observații apare o aglomerare de evenimente, cât de surprinzătoare este ea dacă totul se datorează doar întâmplării?

Problema

Fie \(X_1, X_2, \dots, X_N\) variabile aleatoare independente, cu repartiția Bernoulli de parametru \(p\). Pentru o fereastră de lungime \(m\), statistica de scanare unidimensională discretă este

\[ S_m(N) = \max_{1 \le i \le N-m+1} \; \sum_{k=i}^{i+m-1} X_k . \]

Ne interesează probabilitatea \(\mathbb{P}\big(S_m(N) \ge k\big)\), adică șansa ca, undeva în secvență, o fereastră de lungime \(m\) să conțină cel puțin \(k\) succese.

Definiția 1 (Statistica de scanare) Pentru un șir \((X_k)\) și o lungime \(m\), numim statistică de scanare numărul maxim de succese conținute într-o fereastră de \(m\) observații consecutive.

Simularea este calea cea mai directă de a estima această probabilitate și o verificare utilă pentru formulele exacte și pentru aproximări.

Estimare Monte Carlo în R

Cel mai simplu estimator este frecvența relativă din \(n\) simulări independente:

\[ \widehat{P}_n = \frac{1}{n} \sum_{r=1}^{n} \mathbf{1}\{S^{(r)}_m(N) \ge k\}, \qquad \operatorname{se}\big(\widehat{P}_n\big) \approx \sqrt{\frac{\widehat{P}_n (1-\widehat{P}_n)}{n}} . \]

Sumele pe ferestre se obțin din sume cumulate, astfel încât fiecare secvență simulată este scanată în timp liniar.

scan_1d <- function(x, m) {
  # sumele pe ferestre de lungime m, calculate cu sume cumulate
  s <- cumsum(c(0, x))
  max(s[(m + 1):length(s)] - s[1:(length(s) - m)])
}

set.seed(2026)
N <- 1000; m <- 20; p <- 0.05; k <- 6
S <- replicate(10000, scan_1d(rbinom(N, 1, p), m))

p_hat <- mean(S >= k)
se    <- sqrt(p_hat * (1 - p_hat) / length(S))
round(c(estimat = p_hat, eroare_standard = se), 4)
        estimat eroare_standard 
         0.0709          0.0026

Pentru \(N = 1000\), \(m = 20\) și \(p = 0{,}05\), probabilitatea ca o fereastră să conțină cel puțin \(k = 6\) succese este estimată la 0,0709, cu o eroare standard de 0,0026. Într-o singură fereastră numărul mediu de succese este doar \(mp = 1\); scanarea celor \(N - m + 1\) ferestre suprapuse face ca o asemenea aglomerare să devină probabilă.

Figura 1 arată întreaga repartiție simulată a lui \(S_{20}(1000)\); valorile mai mari sau egale cu \(k = 6\) sunt evidențiate.

freq <- table(factor(S, levels = 0:max(S))) / length(S)
cols <- ifelse(as.integer(names(freq)) >= k, "#D55E00", "#0072B2")
par(mar = c(4, 4, 1, 1), las = 1)
barplot(freq, col = cols, border = NA, space = 0.15,
        xlab = "valoarea statisticii de scanare", ylab = "frecvența relativă")

Aceleași simulări dau dintr-odată întreaga coadă a repartiției (Tabelul 1).

ks  <- 4:9
est <- sapply(ks, function(j) mean(S >= j))
knitr::kable(
  data.frame(k = ks, estimat = est,
             eroare = sqrt(est * (1 - est) / length(S))),
  digits = 4, col.names = c("$k$", "estimare", "eroare standard"),
  format.args = list(decimal.mark = ",")
)

Aceeași abordare se extinde la două și trei dimensiuni, unde fereastra devine un dreptunghi sau un paralelipiped, iar simularea este adesea calea cea mai practică pentru a obține valori de referință.
